# Optional icons for the DDRP visualiser

Drop PNG files here to replace the built-in **vector** icons with real images.
The app picks them up automatically — no code change needed. If a file is
missing, the app falls back to its drawn icon.

| File name | Shown as | Suggested asset |
| --- | --- | --- |
| `drone.png` | each drone on the map | a **top-down** drone/quadcopter, transparent background |
| `depot.png` | the depot | a warehouse / delivery hub, transparent background |
| `package.png` | each revealed order | a parcel / box, transparent background |

## Guidelines

* **Format:** PNG with a transparent background (RGBA), square where possible.
* **Size:** ~256 × 256 px is plenty (the app scales them down).
* **Orientation:** the drone is drawn upright; the app does **not** rotate the
  image, so a top-down view looks best.
* **Licence:** use icons you are allowed to redistribute (e.g. public-domain or
  CC0). Note the source here if you add one.

Nothing here is required — the app looks complete out of the box.
